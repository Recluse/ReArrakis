# ReArrakis

Нативная PC-рекомпиляция **Dune — The Battle for Arrakis** для Sega Genesis / Mega Drive: управление мышью, адаптивная карта и зум.

[English README](README.md) · [Сборка и управление](docs/usage-ru.md) · [Статус](docs/status.md) · [Участие в разработке](CONTRIBUTING.ru.md)

ReArrakis заранее переводит исходный код 68000 и Z80 в C и собирает нативный исполняемый файл. Игровая логика работает вместе с рантаймом оборудования консоли. Расширенная карта использует данные ландшафта и процедуры отрисовки спрайтов самой игры.

Проект ещё в разработке. Нативная сборка доступна на Linux и macOS (проверено на Apple Silicon). В исходном проекте первая миссия Атрейдесов проверена до победы; вся кампания пока не проверена.

## Возможности

- Окно SDL2: карта подстраивается под размер и пропорции окна.
- Выбор юнитов, приказы, размещение зданий и меню производства мышью.
- Управление мышью в главном меню, выборе дома и диалогах подтверждения.
- Зум карты 50–100%, прокрутка у края окна и навигация по миникарте.
- Исходный интерфейс поверх карты; полный экран по F11.
- Звук YM2612 и PSG через статически переведённый Z80-драйвер и ymfm.

## Сборка и запуск

Нужен собственный ROM версии **USA**, размером 1 048 576 байт, в исходном формате без перестановки байтов. Сборщик проверяет версию по [профилю](profiles/dune-us.json):

```text
b1bbe73186e0902fa8b2db0f227bf306e3d6a80fe592f927d1aa9d60c0f335ba
```

Ubuntu / Debian:

```sh
sudo apt install git python3 build-essential pkg-config libsdl2-dev
git clone https://github.com/kruzeman/ReArrakis.git
cd ReArrakis
python3 tools/build_dune.py '/путь/к/Dune - The Battle for Arrakis (U) [!].gen'
./run-dune.sh
```

Зависимости для macOS и запуск из Finder описаны в [инструкции](docs/usage-ru.md#macos).

Звук, мышь, адаптивная карта и зум включаются автоматически. Сборка может занять несколько минут. Результат — `build/dune`; данные ROM встроены в этот файл.

Левая кнопка мыши — выбор и подтверждение; правая — приказ или отмена. Край окна прокручивает карту. Колесо меняет масштаб, **0** возвращает 100%, **F11** переключает полный экран, **F3** показывает примерную занятость 68000. Клавиатура: стрелки, **Z / X / C** вместо A / B / C, **Enter** вместо Start.

Подробнее о громкости, диагностике и управлении — в [инструкции](docs/usage-ru.md), об ограничениях — в [статусе](docs/status.md) и [журнале разработки](docs/dune-status.md).

## Разработка

```sh
make test
make demo
```

Эти проверки используют синтетические данные и не требуют ROM. Игровым проверкам в `tools/` нужен локально сгенерированный `build/dune.c`.

Проект выделен из ветки Dune в [GenesisRecomp](https://github.com/kruzeman/GenesisRecomp), на основе общего движка [RROP](https://github.com/kruzeman/RROP). [Архитектура](docs/architecture.md) и [происхождение кода](docs/provenance.md).

## Лицензия

Код проекта — [MIT](LICENSE). Исходники ymfm — BSD 3-Clause; подробности в [уведомлениях о стороннем коде](THIRD_PARTY_NOTICES.md).

Исходная игра и её ресурсы не подпадают под эти лицензии. ROM, извлечённые ресурсы, сгенерированный игровой код и исполняемый файл игры отсутствуют. ReArrakis — независимый фанатский проект.

В отладочной панели F3 строка `SPD: …%` сравнивает виртуальное время консоли
с реальным за интервал от полсекунды. Около 100% — нормальная скорость,
50% — половина скорости. Это не частота обновления игровой логики:
её оригинальные замедления возможны и при 100%. На паузе показывается `--%`.
