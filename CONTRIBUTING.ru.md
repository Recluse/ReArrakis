# Участие в разработке

Сделай форк [ReArrakis](https://github.com/kruzeman/ReArrakis), создай ветку в своём форке и отправь pull request. Опиши проблему, итоговое поведение и проверки. Старайся менять одну задачу за раз.

Основная документация — на английском, дополнение — на русском. При новых результатах обновляй [статус](docs/status.md) и [журнал](docs/dune-status.md).

Для изменений движка запускай `make test`, для синтетической сборки — `make demo`. ROM им не нужен. Проверки Dune требуют собственного поддержанного ROM; указывай дом, миссию и проверенные действия. Изменения отображения не должны менять игровое время и правила симуляции.

Не коммить и не прикладывай ROM, извлечённые ресурсы, сгенерированный игровой C, исполняемые файлы игры и сохранения. Публичные тесты должны использовать синтетические данные. Сохраняй сведения о происхождении кода и сторонние лицензии.

В сообщении об ошибке укажи ОС, коммит, команду сборки, хеш ROM и точную строку ошибки либо последовательность действий. Для визуальных проблем полезен скриншот.
